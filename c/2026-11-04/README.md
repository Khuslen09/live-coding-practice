## C P1. 일주일 기온 기록 (20점 · 10분) — `p1_temp_log.c`
- 입력: `n` (1 ≤ n ≤ 100), 기온 정수 `n`개 (음수 가능)
- 1줄: `Reverse:` 뒤에 입력의 역순 (값마다 앞에 공백 1칸)
- 2줄: `Max: 최고기온 (day 번호)` — 번호는 **1부터**, 최고기온이 여러 번이면 **가장 앞 날**

```
[입력 1]              [출력 1]
5                     Reverse: 11 15 9 15 12
12 15 9 15 11         Max: 15 (day 2)

[입력 2]              [출력 2]
4                     Reverse: -2 -8 -2 -5
-5 -2 -8 -2           Max: -2 (day 2)
```

## C P2. 반 성적표 (30점 · 25분) — `p2_score_table.c`
2차원 배열 `int s[50][3]` 에 학생별 [국어, 영어, 수학] 점수를 저장. 반드시 구현해서 사용:
- `int total_of(int s[][3], int i)` — i번째 학생(0부터) 세 과목 합
- `double subject_avg(int s[][3], int n, int subj)` — 과목 subj(0~2) 평균

입력: `n` (1 ≤ n ≤ 50), 이후 `n`줄에 점수 3개 (0~100)
출력:
1. 학생마다 `#번호 total=합 avg=평균` (번호 1부터, 평균 소수 둘째 자리)
2. `Subject avg: 국 영 수` (각각 소수 둘째 자리, 앞에 공백 1칸)
3. `Top: #번호 (합)` — 합이 같으면 번호가 작은 학생

```
[입력 1]          [출력 1]
3                 #1 total=255 avg=85.00
90 80 85          #2 total=205 avg=68.33
70 75 60          #3 total=285 avg=95.00
100 95 90         Subject avg: 86.67 83.33 78.33
                  Top: #3 (285)

[입력 2]          [출력 2]
4                 #1 total=240 avg=80.00
80 80 80          #2 total=240 avg=80.00
90 70 80          #3 total=220 avg=73.33
100 50 70         #4 total=180 avg=60.00
60 60 60          Subject avg: 82.50 65.00 72.50
                  Top: #1 (240)
```
