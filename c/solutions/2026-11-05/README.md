## P1. 단어 정보 — `p1_word_info.c`

### 1단계: 문제를 "입력 → 저장 → 출력 3줄"로 쪼개기
출력이 Length / Reverse / Upper 세 줄 → 각각 따로 처리하면 돼요. 셋 다 "길이"가 필요하니까 **길이를 제일 먼저** 구해요.

### 2단계: 무엇을 왜 썼나
| 코드 | 왜? |
|---|---|
| `char word[100]` | 최대 99글자 + 끝 표시 `'\0'` 1칸 = 100 |
| `scanf("%99s", word)` | 공백 없는 단어 → `%s` 로 충분. `99` 는 배열 넘침 방지. 배열 이름이 주소라서 `&` 없음 |
| `while (s[len] != '\0') len++;` | C 문자열은 길이를 따로 저장 안 함 → `'\0'` 만날 때까지 세는 게 strlen 의 정체 |
| `for (i = len - 1; i >= 0; i--)` | 마지막 글자는 `word[len-1]` (`word[len]` 은 `'\0'`). 0번까지 포함해야 하니 `>= 0` |
| `word[i] - 'a' + 'A'` | 문자는 정수(ASCII). 'a'~'z', 'A'~'Z' 가 연속이라 "몇 번째 글자인지(- 'a')"를 대문자 시작점(+ 'A')에 더함 |
| Upper 를 **Reverse 다음에** | 원본을 바꾸는 작업이라 마지막에. 순서를 바꾸면 Reverse 가 대문자로 나와요 |

### 3단계: 짜는 순서 (시험장에서 이 순서로)
1. `my_strlen` 먼저 완성 → `printf("Length: %d\n", ...)` 만 찍고 **컴파일·실행**
2. Reverse 반복문 추가 → 실행해서 `hello → olleh` 확인
3. Upper 추가 → 테스트 4개 돌리기
→ 한 번에 다 쓰지 말고 **한 줄 출력마다 실행해 보기**. 출력 형식(콜론 뒤 공백)은 매번 예시랑 눈으로 비교.

## P2. 아이디 검사기 — `p2_id_check.c`

### 1단계: 함수와 main 의 역할 나누기
- `check_id` = **아이디 하나만** 보고 0~4 리턴 (출력 X)
- `main` = n번 반복하면서 결과 출력, Valid 개수, Longest 기록
이렇게 나누면 check_id 는 규칙 순서만 신경 쓰면 돼요.

### 2단계: 규칙 순서 = if 순서 = "먼저 걸린 이유 하나만"
`return` 은 함수를 즉시 끝내요 → 규칙 1, 2, 3, 4 순서대로 `if (...) return 번호;` 를 쓰면 **처음 걸린 것만** 자동으로 리턴돼요.

| 코드 | 왜? |
|---|---|
| `if (len < 4 \|\| len > 12) return 1;` | 범위 밖 = "작거나 **또는** 크거나" → `\|\|` |
| `if (!isalpha(s[0])) return 2;` | 첫 글자만 보면 되니 반복 X |
| 반복 안에서 `if (!isalnum(s[i])) return 3;` | 하나라도 이상하면 바로 실패 |
| `has_digit = 1` 플래그 | "숫자가 **하나라도 있나**"는 끝까지 봐야 알 수 있어요 → 반복 중엔 기록만, 판단은 **반복이 끝난 뒤** |
| `char *reason[] = {"", "length", ...}` | 리턴 번호를 그대로 인덱스로 써서 if-else 5개 대신 한 줄로 출력 |
| `longest[0] = '\0'` | 빈 문자열(길이 0)로 시작 → 첫 OK 아이디가 무조건 더 길어서 들어감 |
| `strcpy(longest, id)` | 배열끼리 `=` 대입 불가 → 복사 함수 |
| `>` (`>=` 아님) | 같은 길이면 **안 바꿈** = 먼저 나온 것 유지 |
| `valid == 0` 이면 `none` | Longest 가 빈 문자열일 때를 따로 처리 |

### 3단계: 짜는 순서
1. `check_id` 에 규칙 1만 쓰고 main 에서 `#i OK / INVALID length` 출력 → 실행
2. 규칙 2, 3, 4 를 하나씩 추가하며 c_p2_1 으로 확인
3. 마지막에 Valid, Longest 추가 → c_p2_2 (none) 확인
