# live-coding-practice

C프로그래밍 · 객체지향프로그래밍(Java) 기말 라이브코딩 대비 — 매일 연습 기록

## 사용법
1. 매일 아침 `days/YYYY-MM-DD/` 폴더에 그날 문제(README.md)와 시작 코드가 올라와요.
2. `git pull` 받고, 타이머 켜고, **AI·자동완성·검색 없이** `c/`, `java/` 안의 시작 코드 파일에 직접 작성해요.
3. 다 풀면 올리기:
   ```bash
   git add . && git commit -m "Day N 제출" && git push
   ```
4. 다음 날 아침 채점 결과와 피드백이 노션에 오고, 모범답안은 `solutions/YYYY-MM-DD/` 에 공개돼요.

## 폴더 구조
```
days/YYYY-MM-DD/
  README.md        오늘 문제
  c/               C 시작 코드 (여기에 풀기)
  java/            Java 시작 코드 (여기에 풀기)
  tests/           채점용 입력·기대 출력
solutions/YYYY-MM-DD/   하루 뒤 공개되는 모범답안
```
